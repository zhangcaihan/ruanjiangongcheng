# 需求文档

## 1. ai规划行程

用户输入出发地，目的地，出发时间，出行方式，出行人数，

系统返回：

- 建议入住区域
- 详细的出行规划，内容包括（出行方式，建议，预算）。见 [举个栗子](example.md)
- 依据天气情况，调整出行计划。

## 2. 根据用户输入，修改行程安排

用户输入： **我还想去总统府**

系统需要依据用户输入，修改行程安排，比如：

- 增加旅游景点

## 3. 杀手功能

1. ：“价格锁定行程”——自动为你找最便宜的组合方案（比人工更省钱）核心点：输入预算（如 800 元、1500
   元）系统自动裁剪路线、替换景点、调整交通方式自动帮你优化成“预算最优解”比如：“我只有 600 块，帮我做广州 2
   天穷游”系统会自动：换掉门票贵的地方优先选择免费景点优选公交/地铁路线提供真实的“穷游最优路线”
2. ：“实时智能纠错行程”——遇到天气/拥堵自动重排路线输入情况：景点爆满下雨了临时封路用户迟到了系统自动给你：✔ 更新后的路线✔
   替代景点✔ 时间同步调整✔ 预估费用变化例如：“天安门下雨了，有没有室内替代安排？”秒级重排。
3. ：“三分钟旅行人格测试”——生成独特风格路线这个可以做得非常有趣：通过 6 个问题，判断用户是：城市探险型休闲松弛型文化深潜型低预算效率型小众收藏型摄影打卡型
4. ：“学生专属线路库”——全国高校出发的高性价比路线比如：“南京大学 2 日周末短途游（150 元）”“广州大学城一天穷游（66 元）”“上海大学生
   100 元夜游路线”只要你们基于数据生成几个模板，就能秒变差异化。
5. ：“行程多模态规划”—路线图 + 时间轴 + 花费自动同步一个真正体验拉满的设计：GPT 生成文字自动转为：行程卡片地图路径时间轴费用分类图
6. ：“AI 旅行搭子聊天模式”—像朋友一样陪你规划你们 PPT 强调“AI
   旅行搭子人格化”，但目前没有真正体现。可以做：“小穷游”人格：专找便宜但好玩的点“吃货搭子”：所有路线都围绕美食“懒人搭子”：避免走太多路“摄影搭子”：专找可出片点用户可选一种人格。社交属性 +
   AI Agent = 极强差异化
